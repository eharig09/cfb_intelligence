How platform entries behave

Website: records the publisher/site endpoint. If you know an actual RSS/Atom URL, add it separately as an RSS endpoint so ingestion has a machine-readable feed.

YouTube / podcast: stores the exact channel/feed you supply for the existing media validation pipeline.

Bluesky: accepts either a handle or profile URL and mirrors the seed into the legacy Bluesky registry that the current poller still reads.
